Kenji's Poker Challenge

A browser-based poker practice simulator — play No-Limit Hold'em against AI opponents across multiple themed venues, manage a persistent bankroll, and track your progress over time.

Features

- Multiple venues with distinct difficulty levels and visual themes (from a relaxed riverboat casino to a high-stakes private room)
- Persistent bankroll — buy-ins, cash-outs, and results are saved locally between sessions
- Session history & reports — review past sessions, download hand histories, and export a PDF summary
- Full in-game economy — shop, loans, a vault, entertainment options, and other side activities
- Adjustable difficulty and table settings — game type, player count, and more

Play

This is a single-page app — no installation or build step required. Just open `index.html` in a browser, or visit the live GitHub Pages link (see repo settings) once enabled.

Tech

Pure HTML, CSS, and JavaScript. Data is stored locally in the browser via IndexedDB, so progress persists across sessions on the same device/browser.
